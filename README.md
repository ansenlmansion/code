## 如何编译运行

已配置 VS Code 全局运行方案，打开任意 `.c` 文件后：

- **一键运行**：点右上角的三角形按钮，程序在终端中运行，可直接输入。
- **调试**：先运行一次生成 exe，再按 `F5`，选择「通用 C/C++ 调试（当前文件）」即可打断点。

命令行手动编译：

```bash
# 单文件项目（如通讯录）
gcc -g main.c -o main.exe

# 多文件项目（如括号匹配，需带上 linkstack.c）
gcc -g bracket.c linkstack.c -o bracket.exe
```

> 全局运行脚本会自动识别 `#include "xxx.h"` 并带上同目录对应的 `.c` 文件，通常无需手动指定。

## 环境说明

- 系统为 UTF-8 代码页，源码中的中文可直接输出，无需额外转码
